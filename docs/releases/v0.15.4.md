## What's new

- DeskBound now checks for updates periodically while it remains open, not only at startup.
- Update checks retry sooner after a temporary network failure.
- Installer updates keep the current application directory, including portable-style locations.
- Setup creates a desktop shortcut by default, and DeskBound protects its own shortcut from Desktop Inbox and Smart Organize.
- Failed or invalid update downloads are removed immediately.

The update flow was verified by installing the published v0.15.3 Setup into an isolated directory, upgrading it in place to v0.15.4, and uninstalling it again. Existing layout and settings files remained unchanged.

## 繁體中文

- 桌伴持續開啟時也會定期檢查更新，不再只於啟動時檢查。
- 暫時無法連線時會較快重試，不會直接等待六小時。
- 使用安裝檔更新時會沿用目前程式位置，包含類似免安裝版的位置。
- Setup 預設建立桌面捷徑；桌面收件匣與智慧整理不會收走桌伴自己的捷徑。
- 下載失敗或完整性驗證失敗時，會立即移除未完成的更新檔。

這次已在隔離資料夾中安裝公開版 v0.15.3、原地升級至 v0.15.4，再正常解除安裝；既有版面與設定檔全程保持不變。
