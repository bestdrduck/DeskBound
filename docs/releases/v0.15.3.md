## What's new

- Optional early startup through a Windows logon task, without running the app as administrator or raising CPU priority.
- Panel icons load in the background so slow icon handlers do not block the interface.
- Fixed VALORANT and Riot Client shortcut icons, including icon paths using forward slashes and custom icon resource indexes.
- The installer preserves the startup method and updates its executable path during upgrades.

Download **DeskBound-Setup.exe** below to install or update. Existing layouts and settings are preserved. Enable early startup in the control center's **Automation** section; actual sign-in timing depends on your system.
