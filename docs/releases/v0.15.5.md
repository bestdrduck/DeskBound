## What's new

- Added a compact list view for panels with many files.
- Switch between icon grid and compact list from Appearance or the panel's right-click menu.
- Each panel tab remembers its own view mode.
- List rows retain selection, multi-select, drag-and-drop, search, folders, and item context menus.

## 繁體中文

- 新增適合大量檔案的精簡清單模式。
- 可從「外觀與排列」或圍欄右鍵選單切換圖示格狀與精簡清單。
- 每個圍欄分頁會分別記住自己的檢視方式。
- 清單模式保留選取、多選、拖放、搜尋、資料夾瀏覽與項目右鍵功能。
