# DeskBound v0.20.0

## English

- Added an offline bilingual Changelog page to the control center, covering every release from v0.12.0 onward.
- Search version names and feature text, expand older entries when needed, and keep the history usable at compact widths.
- Refined panel tab labels with an explicit Microsoft JhengHei UI fallback and consistent SemiBold typography for active and inactive tabs.

## 繁體中文

- 控制中心新增離線中英雙語更新日誌，收錄 v0.12.0 之後的每個版本。
- 可搜尋版本與功能文字，需要時展開較舊項目，並在較窄的視窗中保持可用。
- 分頁標籤明確加入 Microsoft JhengHei UI fallback，並讓目前與非目前分頁維持一致的 SemiBold 字重。
