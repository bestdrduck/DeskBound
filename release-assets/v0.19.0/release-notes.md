# DeskBound v0.19.0

## English

- Large panels now use viewport-first item realization, so off-screen items do not keep WPF controls in memory while scrolling.
- Adds a live Help diagnostics card with panel and Desktop Inbox watcher health, update state, display summary, and version.
- Adds a one-click support ZIP export containing useful anonymous system and feature diagnostics without file names, paths, panel titles, layout contents, or secrets.
- Keeps watcher recovery non-modal and surfaces only aggregate health, so normal panels stay visually quiet.

## 繁體中文

- 大型圍欄改用畫面優先建立項目，畫面外項目不會持續保留 WPF 控制項，滾動時會自動回收與建立。
- 使用說明新增即時診斷卡片，顯示圍欄／桌面收件匣監看狀態、更新狀態、螢幕摘要與版本。
- 可一鍵匯出支援 ZIP；內容只包含匿名系統與功能診斷，不含檔名、路徑、圍欄名稱、版面內容或秘密資訊。
- 監看復原維持非強制視窗，平時只顯示整體狀態，不干擾一般圍欄操作。
